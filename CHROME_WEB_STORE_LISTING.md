# TabYou Chrome Web Store listing

## Extension name

TabYou — New Tab & Bookmark Manager

## Short description

Turn every new tab into a fast, visual workspace for your open tabs, bookmarks, folders, spaces, and saved sessions.

## Detailed description

TabYou replaces Chrome’s new-tab page with a clean workspace for managing open tabs and bookmarks without losing your place.

Drag an open tab from the sidebar into a colour-coded folder to save it. Arrange folders into spaces, reorder bookmarks, stash a complete browsing session, and find what you need without digging through Chrome’s bookmark menus.

### Everything visible in one place

- See the tabs in your current browser window.
- Drag tabs into folders to save them as bookmarks.
- Reorder bookmarks and folders with drag and drop.
- Collapse folders when you want a quieter workspace.
- Create separate spaces for projects, clients, research, or personal browsing.
- Rename or delete spaces directly from the new-tab page.

### Fast tab and session management

- Stash all open tabs into a folder in one click.
- Reopen every bookmark in a folder as a saved session.
- Find and close duplicate browser tabs.
- Expand Recently Closed directly in the sidebar.
- Open bookmarks in the current tab, or use Command/Ctrl-click to open them quietly in a background tab.

### Bookmark tools that stay out of the way

- Edit a bookmark’s title and URL from a compact popover.
- Copy or delete a bookmark from the same menu.
- Undo bookmark renames and deletions.
- Mark bookmarks that have not been opened for a month.
- Refresh all saved favicons from Settings.
- Search open tabs, saved bookmarks, URLs, and folder titles.

### Bring your existing bookmarks

- Import standard Chrome bookmarks. Bookmark folders become TabYou folders.
- Import an official Tabme JSON export, including spaces, folders, groups, colours, bookmarks, and available favicons.
- Export a complete TabYou JSON backup whenever you want.

### Free and open source forever

TabYou has no Pro plan, subscription, account requirement, advertising, or paid feature gate. The complete extension is intended to remain free and open source forever.

Your spaces, folders, bookmarks, and settings stay in Chrome’s local extension storage. TabYou has no cloud account or sync service and does not sell your browsing data.

### Inspired by Tabme, independently built

TabYou is inspired by the visual organisation and tab-management ideas in Tabme. It is an independent open-source project and is not affiliated with, endorsed by, or maintained by Tabme or its creators.

## Category

## Single-purpose statement

TabYou replaces the Chrome new-tab page with a local workspace for organising open tabs, bookmarks, folders, spaces, and saved browsing sessions.

## Permission explanations

### Tabs

Used to display, activate, close, stash, and detect duplicate tabs in the current browser window, and to open saved bookmarks.

### Sessions

Used to show and restore Chrome’s recently closed tabs.

### Storage

Used to save folders, spaces, bookmarks, preferences, and layout information locally in the browser.

### Favicon

Used to display and refresh website icons beside tabs and saved bookmarks.

### Bookmarks

Used only when the user chooses to import their existing Chrome bookmark folders into TabYou.

## Privacy disclosure

TabYou does not require an account and does not include advertising, analytics, telemetry, or a cloud backend. Tab and bookmark data is processed for the extension’s user-facing features and stored locally through Chrome extension storage. TabYou does not sell or transfer user data.
